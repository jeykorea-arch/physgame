# 전기의 여정 — 3차시 AR 학습 게임

물리학 II 수업용 설치 없는 반응형 WebAR 학습 게임입니다. 여섯 마커와 `L1-Q01~L3-Q30`, 동일 내용의 비AR 모드, 교사용 진행 화면을 포함합니다.

공개 수업 주소: https://jeykorea-arch.github.io/physgame/

- 학생: 위 주소에서 1·2·3차시를 선택하거나 `?lesson=1`, `?lesson=2`, `?lesson=3`으로 바로 접속
- 교사: https://jeykorea-arch.github.io/physgame/?teacher=1
- 교사용 화면에서 `실시간 수업 열기`를 누른 뒤 표시되는 QR을 학생에게 안내
- 학생이 기본 주소를 직접 열었다면 교사 화면의 6자리 코드를 `교사용 진행판에 연결하기`에 입력

## 이 컴퓨터에서 실행

`start-local.cmd`를 더블클릭하거나 다음 명령을 실행합니다.

```powershell
cd C:\Users\seo\Desktop\my-think-thank\physgame\web-app
npm.cmd install
npm.cmd run dev:pages
```

브라우저에서 `http://localhost:5173`을 엽니다. 실제 스마트폰 카메라는 HTTPS인 공개 수업 주소에서 시험하세요.

## 구현 범위

- 1차시: 발전·고전압 송전·변압, L1-Q01~L1-Q10
- 2차시: 다이오드 정류·축전기 평활·트랜지스터 스위칭, L2-Q11~L2-Q20
- 3차시: 여섯 마커를 재활용한 고장 진단·계통 개념·전체 여정, L3-Q21~L3-Q30
- 관찰 → 예측 → 조작 → 퀴즈 → 피드백, 첫 시도 10점·재시도 7점·안내 완료 5점
- 차시별 `localStorage` 진행 복원, AR/비AR 동일 문항·정답·피드백
- 교사용 화면: 차시 QR, 45분 타이머, 실시간 익명 접속·단계·문항·점수 현황, 수동 현황 대체 모드, 투사용 안내, 익명 결과 JSON 가져오기, 문항 통계 CSV/JSON 내보내기

## 실시간 수업 진행판

Firebase Realtime Database의 무료 Spark 요금제로 학생 여러 기기의 진행을 자동 집계합니다. 실명·학번 대신 무작위 익명 별칭만 사용하며 현재 단계, 완료 문항 수, 점수, AR/비AR 모드와 마지막 접속 시각만 전송합니다. 사진·카메라 영상·마커 프레임은 전송하지 않습니다. 학생은 다른 학생 데이터를 읽을 수 없고, 수업을 연 교사 브라우저만 해당 수업의 전체 익명 현황을 읽을 수 있습니다.

교사용 화면은 실시간 수업을 열기 전에는 QR을 표시하지 않습니다. `실시간 수업 열기` 뒤 생성된 QR에만 수업 코드가 포함됩니다. 학생이 기본 주소로 접속한 경우에는 같은 화면에 표시된 6자리 코드를 직접 입력하면 됩니다.

무료 한도는 동시 연결 100개입니다. 한도를 넘기면 과금되지 않고 해당 서비스가 제한되므로 한 학급 단위로 사용하세요. 교사 브라우저의 사이트 데이터를 삭제하면 이전 수업 코드의 소유권을 복원할 수 없으므로, 수업 중에는 브라우저 데이터를 지우지 마세요.

## 검증 명령

- `npm.cmd run compile:targets`: 원본 6개 마커 순서와 해시 검증 후 `targets.mind` 재생성
- `npm.cmd test`: 30문항 정답·오답·재시도·배점·진행 복원·AR/비AR 일치·개인정보 규칙 검사
- `npm.cmd run test:live`: `.env.local`을 사용해 교사 개설→학생 익명 접속→진행 갱신→종료를 실제 Firebase에서 왕복 검사
- `npm.cmd run lint`: 소스 정적 검사
- `npm.cmd run build:pages`: GitHub Pages 정적 빌드

## 환경변수와 개인정보

Firebase 웹 설정값은 Git에 포함되지 않는 `.env.local`에 저장하고, GitHub 배포에서는 Actions Secrets로 주입합니다. 필요한 변수 이름은 `.env.example`에 있습니다. `VITE_` 접두사 값은 최종 브라우저 번들에서 보일 수 있으므로 관리자용 비밀 키나 서비스 계정 키를 넣지 마세요.

카메라는 MindAR 마커 인식에만 사용됩니다. 실명·학번·프레임·사진·영상은 저장하거나 전송하지 않습니다. 진행과 점수는 새로고침 복원을 위해 학생 브라우저에도 저장되며, 수업 QR 접속 중에는 익명 진행 요약만 Firebase에 전송됩니다. 교사용 결과 파일에도 실명·학번은 포함되지 않습니다.
